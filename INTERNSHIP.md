### **What was the most challenging thing you faced?**
The voice agent project was the most challenging
The biggest challenge was coordinating multiple components in real time. A traditional API workflow can tolerate some delay, but in a voice conversation even a few seconds feels unnatural. I had to understand how the WebSocket communication, AI processing and text-to-speech pipeline interacted and identify where latency could occur.
That taught me to think about a system as an end-to-end pipeline rather than looking at each component independently
### **Tell me about a failure**
I learned that getting each individual component working isn’t the same as building a good product. The interfaces between components often become the real bottleneck.
